Dotfiles hold configuration. 

.bashrc - shell startup config
.ssh/ - SSH keys and known hosts
.aws/, .kube/ - cloud and cluster credentials
.gitignore, .env - project-level config

That's long listing, all files (hidden included), human-readable sizes : ls -lah ~

ls -a | wc -l : It counts the words given by ls

ls -a ~ | grep '^\.'      # only entries starting with a dot (dotfiles)

Help commands:
ls --help
man ls
ls -h

You want to list files in /var/log sorted by size, but you don't remember which flag ls uses for that. What do you do?
Run `ls` with the `--help` flag and skim the output (or pipe it through `grep` to filter) for the flag you want.
