mkdir notes                     # create a directory in the current directory
mkdir /root/projects            # create at an absolute path

Plain mkdir fails if the parent folder doesn't already exist. mkdir -p creates every missing parent along the way:
mkdir -p /root/projects/api/src

whoami -> root : Username
hostname -> Desktop1 : machine name

cat /etc/hostname          # the machine's name, as stored on disk
cat /etc/os-release        # which Linux distribution and version

Multiple tasks at once using && operator:
echo "Linux">kernel.txt && cat kernel.txt && ls / >root-listing.txt && cat root-listing.txt

uname -s prints the kernel name. Every Linux machine, no matter which distribution, reports "Linux". Darwin is what macOS reports. Windows and BSD are their own kernels entirely. When you're troubleshooting a script that needs to know which system it's running on, uname is the standard way to ask.
